## Обязательные колонки

| Колонка | Что в ней |
|---|---|
| Приоритет | 1..N — выше = лучше отклик |
| Компания | названием; «(название скрыто)» если скроют |
| Позиция | как в вакансии |
| Город | фактическое место работы |
| Опубл. | дата публикации из карточки (не из кэша!) |
| Вилка | с пометкой «на руки»/«до вычета»; «н/д», если не указана |
| Совпадение | % — экспертная оценка с обоснованием в комментарии |
| Комментарий | почему этот приоритет + чем закрыты фильтры вакансии |
| Ссылка | прямой URL карточки вакансии |

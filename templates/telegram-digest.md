# Формат дайджеста для Telegram

## Правила

- Одно сообщение, ≤ ~4000 символов (лимит Telegram 4096; если больше — разбить на 2 сообщения по 3800).
- Ссылки — прямым текстом (без markdown-разметки): Telegram не рендерит `[текст](url)` в обычном сообщении.
- Разделитель строк — обычный перенос; без жирного (** не работает без parse_mode).
- Обезличенно и коротко: факты, цифры, ссылки.

## Шаблон

```
📋 Дайджест вакансий [окно ДД.ММ–ДД.ММ.ГГГГ] (проверены, активны)

[спокойная неделя? — одна строка: X активных по профилю, Y новых]

1. [Позиция] — [Компания], [Город], [вилка]. Публ. [ДД.ММ]
[ссылка]
([совпадение ~NN%; одна строка смысла])

2. ... (всего до 5)

Ещё [N] ([имена через запятую]) — в таблице.
✅ Подтверждены из прошлых недель: [список] — окна открыты.
Рынок недели: [одна строка — что изменилось].
```

## Вариант «ничего не найдено»

```
📋 Дайджест вакансий [окно]
За неделю подходящих вакансий не найдено. Проверю ещё раз [дата следующего прогона].
```

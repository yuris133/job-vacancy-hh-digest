# Каркас сопроводительного письма под конкретную вакансию

Скелет письма, которое сработало 7 раз за ноябрь 2026 в проекте-родоначальнике (пищевой FMCG-кандидат, руководящие роли). Адаптируйте под свою отрасль — структура и логика универсальны.

---

## Структура (по порядку)

1. **Приветствие + первый абзац «совпадение»** — почему конкретный профиль закрывает конкретную вакансию, в одной фразе с самым сильным артефактом (цифра/сертификат/уникальное сочетание).
2. **3–6 пунктов-буллетов** — каждая обязанность вакансии закрыта фактом кандидата с результатом. Порядок: сначала то, что в вакансии приоритезировано.
3. **Закрытие очевидных фильтров вакансии** — язык/уровень/релокация/командировки: честно заранее, без вранья и лишних отрицаний.
4. **Подпись** — имя, телефон, e-mail.

## Каркас текста

```
Здравствуйте!

Откликаюсь на позицию [точное название из вакансии]. Ваш главный запрос —
[одна фраза со словами из вакансии] — это точный контур моей работы:
[2 строки профиля с самым сильным подтверждением: роль, масштаб, цифра].

По обязанностям:
- [Обязанность 1 их] → [факт + измеримый результат]
- [Обязанность 2 их] → [факт + цифра]
- [Обязанность 3 их] → [факт]
- [Обязанность 4 их] → [факт]

По требованиям:
- Стаж: [перекрываю: N лет против требуемых M] — [одна фраза против «овердрифт-страха»,
  если разница велика];
- [фильтр-вопрос, напр. язык]: [честная позиция, 1–2 предложения, без обещаний, которые не
  планируете выполнять].

[Строка про локацию/релокацию/командировки — строго по факту.]

С уважением,
[Имя], [телефон], [email]
```

## Правила, которые дали результаты (не нарушать)

- **Письмо ≤ ~200 слов** — поле отклика hh короткое, эссе не читают.
- **Каждый пункт = факт, а не качество.** Никаких «стрессоустойчивый», «командный»; только «переработка 32%→74%».
- **Честность про слабые фильтры обязательна** — ошибка в языке/релокации всплывает на скрине и сжигает goodwill.
- **Овердрифт** (опыта сильно больше требуемого) снимается явно: «не переросток, а готов выполнять роль качественно».
- **Вилку в письме не обсуждать** — вопрос задать на звонке.
- **Бренд-работодателя называть**, если вакансия в той же отрасли — это плюс, а не риск.

## Примечание внизу файла (себе, не отправлять)

- Кому сопроводительное адресовано, какие фильтры вакансии (что открылось при прочтении страницы), какова оценка шансов и ожидания.
